# Hand lettering for printed gift cards and coupons

Export each heading from your design as a **transparent PNG** (black or grey
lettering, at least 600 px wide) and save it here with these exact names:

| File | Lettering |
| --- | --- |
| `coastline-prints.png` | "Coastline Prints" on one line |
| `gift-card.png` | "Gift Card" (grey) |
| `coupon.png` | "Coupon" (grey) |
| `redeem.png` | "Can be redeemed at:" |
| `questions.png` | "Questions or concerns?" |

Any file that's missing prints as plain bold text instead.

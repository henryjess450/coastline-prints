# Receipt fonts

Receipts print in **Arimo** by default (bundled; metric-identical to Arial).

To print in real **Arial**, copy these two files from a Windows PC into this folder:

- `C:\Windows\Fonts\arial.ttf`
- `C:\Windows\Fonts\arialbd.ttf`

Arial is licensed by Microsoft, so `.ttf` files here are never committed to git.
